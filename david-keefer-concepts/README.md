# David Keefer — Three Website Concepts

Compare three browser-only HTML designs at `/david-keefer-concepts/`.

- `classic/`: Classic Navy, adapted from the latest no-artwork preview.
- `boxcar/`: Design B (Boxcar), uploaded by the user.
- `green/`: Design C (Green), uploaded by the user.

All three use their own localStorage and IndexedDB namespaces to prevent demo edits/uploads bleeding between designs. There are no real logins and no cloud data persistence. Do not upload confidential files.

Adding these files does not modify existing root-level pages in this repository or any Cloudflare settings.
